# EmoteOffhand

[![forthebadge made-with-java](https://forthebadge.com/images/badges/made-with-java.svg)](https://java.com/)

[![License: MIT](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)
[![Discord](https://img.shields.io/discord/613163671870242838.svg?color=%237289da\&label=discord)](http://discord.geysermc.org/)

EmoteOffhand is an extension for Geyser which allows players to emote in order to trigger an offhand switch.

Right-click also follows Java Edition hand order. The main hand is used first. If that click does nothing, the offhand is used, so a block, bucket, food, or firework rocket in the offhand works while a tool or weapon stays in the main hand. A shield is raised by sneaking, not by right-click. Requires Geyser 2.12.0 or newer.
